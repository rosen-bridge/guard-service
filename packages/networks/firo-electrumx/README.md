## Introduction

A package to be used as network api provider for @rosen-chains/firo package, using ElectrumX TCP JSON-RPC protocol.

## Installation

npm:

```sh
npm i @rosen-chains/firo-electrumx
```

yarn:

```sh
yarn add @rosen-chains/firo-electrumx
```

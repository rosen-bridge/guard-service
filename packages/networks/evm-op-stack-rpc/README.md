## Table of contents

## Introduction

A package to be used as network api provider for any OP-Stack based chains that are built on the @rosen-chains/evm package

## Installation

npm:

```sh
npm i @rosen-chains/evm-op-stack-rpc
```

yarn:

```sh
yarn add @rosen-chains/evm-op-stack-rpc
```
